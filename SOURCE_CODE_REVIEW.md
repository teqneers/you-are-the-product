# Source code review (addons.mozilla.org)

The extension is built with [WXT](https://wxt.dev) and Vite, which bundle and minify the code.

## Environment

- macOS or Linux, Node.js 24 or newer, npm 11 or newer
  (developed with Node.js 26.12.1 and npm 12.2.1)
- No other tools, no network access needed for the build

## Build

```sh
npm ci
npm run build:firefox
```

The extension is written to `.output/firefox-mv2/`. `npm run zip:firefox` creates the same files as a zip.

## Bundled data

The JSON files in `data/` are bundled as they are. They are generated by the scripts in `scripts/`
(`npm run trackers`, `npm run logos`, `npm run reach`, `npm run brokers`, `npm run geo`,
`npm run vendors`) from public sources;
the build does not regenerate them. `data/site-categories.json` is written by hand.

| File | Source |
|---|---|
| `data/trackers.json` | DuckDuckGo Tracker Blocklists (CC BY-NC-SA 4.0) plus `data/extra-trackers.json` |
| `data/logos.json` | Favicons of the company websites in `data/logo-sources.json`, shrunk to 32 px PNG |
| `data/vendor-names.json` | IAB Europe Global Vendor List: vendor ids and names only, current and older versions |
| `data/reach.json` | WhoTracks.me by Ghostery (CC BY 4.0): share of popular websites per company |
| `data/brokers.json` | US state data broker registries (public records) matched to company names |
| `data/site-categories.json` | Hand-written categories of popular websites (health, jobs, news …) |
| `public/geo/*.bin.gz` | DB-IP IP to Country Lite (CC BY 4.0), compacted IP ranges → country code |

## What the code does

- `entrypoints/background.ts` observes requests (`webRequest.onBeforeRequest`, `onBeforeRedirect`,
  `onHeadersReceived` for the lifetime in `Set-Cookie` headers, `onResponseStarted` for the server IP, which is
  looked up in the bundled country table; all without blocking) and keeps statistics in `storage.local`. Nothing is sent anywhere; the only own requests are favicon downloads.
  The IAB vendor names are bundled (`data/vendor-names.json`, `lib/vendor-list.ts`).
- `entrypoints/page-probe.ts` runs in pages to read Prebid.js auction events and the TCF consent string and
  to notice fingerprinting API calls and the names and lifetimes (not values) of cookies scripts set; it reports
  to the content script via `postMessage`.
- `entrypoints/clicks.content.ts` notes the first click and whether a cookie banner button says accept or reject.
- `entrypoints/typing.content.ts` passes email addresses typed into forms to the background, which keeps them only
  in memory to recognise them in third-party requests (`lib/form-leaks.ts`).
- `entrypoints/replay.content.ts` keeps the last 30 seconds of mouse movements and the number of key presses in
  memory, for the "you are being recorded" replay in the user interface.
- `entrypoints/{popup,sidepanel,dashboard}` are the user interface.
