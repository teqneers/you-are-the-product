# You Are The Product

A browser extension for Chrome, Firefox and Safari that shows live which companies follow you while you browse,
what they learn and who buys your attention. It blocks nothing and sends nothing away.

## Install

- [Chrome Web Store](https://chromewebstore.google.com/detail/you-are-the-product/abjemhhjkaelkbiabifhfccpcdmmbiag)
  (also for Edge, Brave and other Chromium browsers)
- [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/you-are-the-product/)
- Safari (macOS): Mac App Store coming soon
